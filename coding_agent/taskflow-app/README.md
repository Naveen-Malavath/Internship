# taskflow-app

Full-stack application with react frontend and fastapi backend.

## Structure

- `frontend/` - react application
- `backend/` - fastapi API

## Setup

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Backend:
```bash
cd backend
npm install  # or pip install -r requirements.txt
npm run dev  # or uvicorn main:app --reload
```
