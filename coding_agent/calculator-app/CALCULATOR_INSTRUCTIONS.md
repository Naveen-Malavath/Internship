# Calculator App

## Standalone Calculator (No Installation Required)

### How to Use:
1. Open `standalone-calculator.html` in any web browser (Chrome, Firefox, Edge, Safari)
2. The calculator is fully functional and ready to use!

### Features:
- ✅ Basic arithmetic operations (+, -, ×, ÷)
- ✅ Decimal point support
- ✅ Clear (C) and Delete (DEL) functions
- ✅ Keyboard support for easy input
- ✅ Responsive design
- ✅ Clean, modern UI
- ✅ Real-time calculation display

### Keyboard Shortcuts:
- **Numbers (0-9)**: Enter numbers
- **+, -, *, /**: Arithmetic operations
- **Enter or =**: Calculate result
- **Escape**: Clear all
- **Backspace**: Delete last digit
- **.**: Decimal point

### Calculator Operations:
1. Click number buttons or use keyboard to enter numbers
2. Click operation buttons (+, -, ×, ÷) to select operation
3. Enter second number
4. Click "=" or press Enter to see result
5. Use "C" to clear all or "DEL" to delete last digit

## React Calculator (Requires Node.js)

If you want to run the React version:

### Prerequisites:
- Node.js (v16 or higher)
- npm (comes with Node.js)

### Installation:
```bash
cd calculator-app
npm install
```

### Run Development Server:
```bash
npm run dev
```

Then open your browser to the URL shown (usually http://localhost:5173)

### Build for Production:
```bash
npm run build
```

The built files will be in the `dist` folder.

---

## Which Version to Use?

- **Standalone HTML**: Best for quick use, no installation needed, works offline
- **React Version**: Best for development, modern framework, component-based architecture

Both versions provide the same calculator functionality!
